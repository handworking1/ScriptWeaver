## 快速上手

### 1. 安装

从 [Releases](../../releases) 下载 `叙世-x64.exe`，双击运行。无需安装，绿色便携。

### 2. 配置 API

进入 **AI 配置** 页面 → 点击「+ 添加配置」：

- 在快捷预设中选择你的模型（如 `DeepSeek V4 Pro`）
- 填入 API Key（加密存储，不会泄露）
- 点击「🔌 测试」验证连接
- 测试通过后点「保存」

> 使用本地 Ollama：安装 [Ollama](https://ollama.com)，运行 `ollama pull qwen2.5:14b`，然后在叙世中选择 `Ollama 本地` 预设即可。无需 API Key。

### 3. 创建剧本

进入 **剧本管理** → 点击「+ 新建剧本」：

1. 输入标题，如「仙途」
2. 点击「✨ AI 补全」自动生成世界观和背景
3. 勾选类型标签（如：玄幻、修仙、爽文）
4. 展开「更多设定」填写主线、支线、金手指等
5. 点击「保存」

> 💡 首次使用？无剧本或无 AI 配置时，聊天页会自动显示三步引导卡片，带你快速上手。

### 4. 开始对话

进入 **聊天** 页面：

1. 选择剧本 → 选择角色 → 选择 AI 配置
2. 选择聊天模式（角色对话 / 世界参与）
3. 配置回复长度和互动选项
4. 点击「我要去了」

## 🤖 AI 剧本讨论

独立的剧本讨论页面，和 AI 按**十二步工作流**协作：

1. **第零步**（可选）：对标作品学习 → AI 解析文风、世界观、情节模式
2. **第一步**：一句话概括（25 字：谁+什么情况+什么方式+什么结果）
3. **第二步**：一段式概括（三幕结构+三次灾难+道德前提）
4. **第三步**：一页人物介绍（人名/身份/目标/抱负/价值观/矛盾）
5. **第四步**：一页大纲（可配置 A故事级/B幕级/C序列级/D场景级）
6. **第五步**：人物大纲（深挖过去经历和原生家庭）
7. **第六步**：四页大纲（每段扩展为一页）
8. **第七步**：动态实体知识库（追踪角色/物品/地点变化）
9. **第八步**：场景清单
10. **第九步**：规划场景（视点人物/目标/冲突/挫折）
11. **第十步**：生成全文
12. **第十一步**：书名与简介

### 特殊功能

- **💡 快捷提问**：空白区三个快捷按钮——「帮我想一个世界观」「帮我设计一个主角」「帮我规划剧情结构」，一键开始讨论
- **👥 提取角色**：点击按钮，AI 自动从讨论中识别所有角色 → 点击角色名一键添加到角色管理
- **📝 生成剧本**：讨论完成后一键生成完整剧本，直接保存

| 模式 | 说明 |
|------|------|
| 💬 角色对话 | 1v1 沉浸式，AI 完全融入所选角色 |

### 聊天功能

- **流式输出**：AI 回复逐字显示，打字机效果
- **选项卡片**：AI 回复中的 `[SUGGESTIONS: 选项1 | 选项2 | 选项3]` 自动转为可点击卡片
- **编辑消息**：hover 用户消息出现编辑按钮，修改后重新生成
- **重新生成**：点击按钮重新生成最后一条 AI 回复
- **对话分支**：在当前节点创建分支对话，独立发展
- **剧情总结**：点击「📋 总结」AI 生成当前剧情摘要
- **多对话切换**：点击「💬 对话」按钮弹出列表，随时切换
- **🔍 对话内搜索**：头部搜索框实时过滤消息，显示匹配条数
- **📜 剧本速览**：点击「📜 剧本」侧边抽屉查看完整设定（世界观、主线、金手指等）
- **↩ 撤销发送**：一键删除最后一条用户消息及 AI 回复
- **快捷输入**：自定义短语按钮，一键发送

### @私聊（世界模式专属）

在世界参与模式下，输入 `@` + 角色名前缀即可唤起角色选择面板：

```
你: @苏
┌─────────────────────┐
│ 苏灵儿  · 小师妹    │  ← 点击选择角色
│ 苏长老  · 宗门前辈  │
└─────────────────────┘
```

- 选择后自动创建新的私聊标签页，与该 NPC 进行独立对话
- 支持多字姓名（上官婉儿、欧阳锋等），中文 Unicode 精确匹配
- 各 NPC 私聊互不干扰，切换标签即可回到世界主线

### 角色图鉴

点击聊天页顶部「📖 图鉴」按钮打开右侧面板：

| 功能 | 说明 |
|------|------|
| 🤖 AI 分析 | 一键从当前对话中提取所有出场角色（姓名、性格、好感度、身材、状态等） |
| + 添加 | 手动添加角色卡片 |
| ✕ 删除 | 移除角色 |
| 名字 | 可编辑角色名 |
| 性格 | 自由文本 |
| 好感度 | 0-100 滑块 + 7 级标签（挚爱💕/喜欢/友好/中立/冷淡/敌视😠） |
| 身材 | 外貌体型描述 |
| 性癖 | 偏好标记 |
| 状态 | 健康/受伤/昏迷等 |
| 备注 | 与主角的关系、特殊能力等 |

所有数据持久化保存至数据库，与剧本关联，切换对话不丢失。

### AI 思考中 & 错误处理

**AI 思考中指示器**：发送消息后、AI 开始回复前，输入框上方显示独立脉动条：

```
┌─────────────────────────────────────────────┐
│ ▓▓▓▓░░░░ AI 思考中...                       │  ← 脉动条
│ [___________________________] [停止]         │
└─────────────────────────────────────────────┘
```

**错误提示**：API 调用失败时顶部弹出 toast 风格横幅，5 秒自动消失，也可手动 ✕ 关闭。常见错误自动翻译为中文提示：

| 原始错误 | 显示为 |
|---------|--------|
| HTTP 401 | Key 无效，请检查 API Key |
| HTTP 429 | 请求过于频繁，请稍后再试 |
| 网络断开 | 无法连接到 API 服务器 |
| 请求超时 | 请求超时，请检查网络 |

**TokenBar 提示**：hover 侧边栏的 Token 用量条可查看上下文窗口剩余容量和费用估算含义。

### [帮回] 核心辅助系统 v3.1

> 在剧本设置中开启后，AI 将成为你的专业叙事助手，支持以下指令：

**角色外分析指令**（在对话中输入即可触发）：

| 指令 | 功能 |
|------|------|
| `帮回剧情总结` | AI 生成核心事件、人物状态、关键转折的完整大纲 |
| `帮回章节规划` | 生成新章节的：核心目标+完成条件、关键NPC及动机、风险与机遇、可埋伏笔 |
| `帮回爽点分析` | 评估铺垫-爆发结构、期待感钩子，指出平淡段落 |
| `帮回人设检查 [角色名]` | 检查角色行为/对话一致性，高亮人设崩塌风险 |

**角色内行动指令**（AI 直接代为演绎并衔接 NPC 回应）：

| 指令 | 风格 |
|------|------|
| `帮回主动1` | 直接果断行动，推进目标，情感外放 |
| `帮回主动2` | 巧妙策略性主动，语言/信息操控 |
| `帮回被动1` | 外部压力下的犹豫/退让/顺从 |
| `帮回被动2` | 内在情感驱动的依赖/逃避/脆弱 |
| `帮回黑暗1` | 心理层面的掌控欲、操纵、暗黑特质 |
| `帮回黑暗2` | 直接侵略行为、占有、极致细节描写 |
| `帮回推进1` | 宏观第三方旁白，宏大叙事/转折/氛围 |
| `帮回推进2` | 微观细节旁白，感官/微表情/心理 |

> 在指令后添加 `[选项]`（如 `帮回主动1 [选项]`）可触发选项引导模式，AI 会提供 2-3 个选项供选择。

**例子**：

```
你: 帮回被动1
AI: (根据当前剧情构思懦弱的用户行动并演绎，紧接着NPC做出回应)

你: 帮回章节规划
AI: 
--- 角色外 ---
【第3章：宗门考核】
核心目标1：通过入门考核（完成条件：击败3名同阶对手）
核心目标2：结识关键人物（完成条件：与至少1名同门建立好感度60+）
关键NPC：大师兄赵无极（竞争关系）、小师妹苏灵儿（潜在盟友）
风险：考核中可能暴露金手指
```

## 🛠 开发

### 技术栈

Electron 33 + React 18 + TypeScript + Vite 6 + Tailwind CSS 3 + Zustand 5 + SQLite (sql.js WASM)

### 本地运行

```bash
git clone https://github.com/yourname/scriptweaver.git
cd scriptweaver
npm install
npm run dev          # 开发模式
npm run typecheck    # 类型检查
npm run build:win    # 打包 Windows
npm run build:mac    # 打包 macOS
npm run build:linux  # 打包 Linux
```

### 项目结构

```
├── electron/          # 主进程
│   ├── main.ts        # 窗口、生命周期
│   ├── preload.ts     # 安全 IPC 桥
│   ├── db/            # SQLite CRUD（按实体拆分，11 个模块）
│   ├── safe-storage.ts # 密钥加密
│   └── ipc-handlers.ts # IPC + SSE 流式
├── src/
│   ├── pages/         # 7 个页面
│   ├── components/    # 14 个组件
│   ├── stores/        # 6 个 Zustand store
│   ├── lib/           # 工具函数
│   ├── types/         # TS 类型
│   └── __tests__/     # 单元测试
├── .github/workflows/ # CI/CD
└── package.json
```
