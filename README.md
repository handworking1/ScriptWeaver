## 快速上手

### 1. 安装

从 [Releases](../../releases) 下载 `叙世-x64.exe`，双击运行。无需安装，绿色便携。

### 2. 配置 API

进入 **AI 配置** 页面 → 点击「+ 添加配置」：

- 在快捷预设中选择你的模型（如 `DeepSeek V4 Pro`）
- 填入 API Key（加密存储，不会泄露）
- 点击「🔌 测试」验证连接
- 测试通过后点「保存」

> 使用本地 Ollama：安装 [Ollama](https://ollama.com)，运行 `ollama pull qwen2.5:14b`，然后在叙世中选择 `Ollama 本地` 预设即可。无需 API Key。

### 3. 创建剧本

进入 **剧本管理** → 点击「+ 新建剧本」：

1. 输入标题，如「仙途」
2. 点击「✨ AI 补全」自动生成世界观和背景
3. 勾选类型标签（如：玄幻、修仙、爽文）
4. 展开「更多设定」填写主线、支线、金手指等
5. 点击「保存」

### 4. 开始对话

进入 **聊天** 页面：

1. 选择剧本 → 选择角色 → 选择 AI 配置
2. 选择聊天模式（角色对话 / 世界参与）
3. 配置回复长度和互动选项
4. 点击「我要去了」

## 📜 剧本管理

### 基础设定

| 字段 | 说明 |
|------|------|
| 标题 | 剧本名称 |
| 创作模式 | 沉浸扮演 / 上帝视角 / 混合 |
| 世界观 | 一句话概括世界设定 |
| 故事背景 | 详细的背景描述 |
| 对标作品 | AI 会学习其文风和世界观 |
| 时代背景 | 如"近未来赛博朋克 2077" |
| 主角困境 | 多层级绝境：宏观+中观+微观+个人 |
| 金手指 | 主角独有能力或信息差 |
| 年龄规则 | 如 18+ / 全年龄 |

### 类型标签

内置 40+ 标签，按四类组织，点击即选：

- **主要题材**：言情、玄幻、仙侠、悬疑、科幻、奇幻、脑洞、都市、历史、古言、无CP
- **核心情节**：重生、穿越、穿书、系统、无限流、复仇、升级流
- **热门设定**：爽文、屌丝逆袭、废柴流、打脸爽文、追妻火葬场、马甲文、真假千金、迪化文、发疯文学、虐文、CP塑造
- **背景职业**：种田、宫斗、末世、娱乐圈、总裁、灵异、赛博朋克、商战、冒险

### 扩展设定（展开「更多设定」）

| 字段 | 说明 |
|------|------|
| 主线任务 | 主要剧情线索和目标 |
| 支线任务 | 可选分支剧情 |
| 环境描述 | 气候、地理、建筑、科技水平 |
| 地图 | 区域划分、关键地点、路径 |
| 事件时间线 | 按时间顺序的关键事件 |
| 章节/幕 | 卷/幕/章节划分 |
| 数据/其他 | 势力、等级、货币、特殊规则 |
| 执行严格度 | 严格 / 宽松 |
| 工作流模式 | 引导 / 灵活启动 |
| 前情提要 | AI 每次回复含提要 |
| 定期总结 | AI 每 10 轮内部总结 |
| 规则自检 | AI 自我检查规则偏离 |

### AI 辅助

- **✨ AI 补全**：输入标题后点击，AI 自动填写空白字段
- **💬 讨论**：打开右侧面板，和 AI 深入讨论剧本设定
- **📝 生成**：讨论完成后点击，AI 把讨论内容总结为结构化设定填入表单

## 🤖 AI 剧本讨论

独立的剧本讨论页面，和 AI 按**十二步工作流**协作：

1. **第零步**（可选）：对标作品学习 → AI 解析文风、世界观、情节模式
2. **第一步**：一句话概括（25 字：谁+什么情况+什么方式+什么结果）
3. **第二步**：一段式概括（三幕结构+三次灾难+道德前提）
4. **第三步**：一页人物介绍（人名/身份/目标/抱负/价值观/矛盾）
5. **第四步**：一页大纲（可配置 A故事级/B幕级/C序列级/D场景级）
6. **第五步**：人物大纲（深挖过去经历和原生家庭）
7. **第六步**：四页大纲（每段扩展为一页）
8. **第七步**：动态实体知识库（追踪角色/物品/地点变化）
9. **第八步**：场景清单
10. **第九步**：规划场景（视点人物/目标/冲突/挫折）
11. **第十步**：生成全文
12. **第十一步**：书名与简介

### 特殊功能

- **👥 提取角色**：点击按钮，AI 自动从讨论中识别所有角色 → 点击角色名一键添加到角色管理
- **📝 生成剧本**：讨论完成后一键生成完整剧本，直接保存

## 💬 聊天

### 两种模式

| 模式 | 说明 |
|------|------|
| 💬 角色对话 | 1v1 沉浸式，AI 完全融入所选角色 |
| 🌍 世界参与 | AI 化身 GM，叙述世界、控制全部 NPC |

### 聊天界面

```
┌─────────────────────────────────────────────┐
│ ← 返回  [头像] 角色名  剧本名  [对话][图鉴]  │  ← 顶部栏
│ ████████░░ 1200/1048576 tokens    $0.002    │  ← Token 使用量
├─────────────────────────────────────────────┤
│                                             │
│  AI: 你推开门，映入眼帘的是...               │  ← 消息区
│  📋 可选行动：                               │
│  ┌ ① 走向窗边查看外面的情况 ─────┐          │  ← 选项卡片
│  └ ② 先检查房间是否有危险 ────────┘          │
│                                             │
│                          你: 我走向窗边...    │
├─────────────────────────────────────────────┤
│ [快捷1] [快捷2]                              │  ← 快捷输入栏
│ [___________________________] [发送]         │  ← 输入区
└─────────────────────────────────────────────┘
```

### 聊天功能

- **流式输出**：AI 回复逐字显示，打字机效果
- **选项卡片**：AI 回复中的 `[SUGGESTIONS: 选项1 | 选项2 | 选项3]` 自动转为可点击卡片
- **编辑消息**：hover 用户消息出现编辑按钮，修改后重新生成
- **重新生成**：点击按钮重新生成最后一条 AI 回复
- **对话分支**：在当前节点创建分支对话，独立发展
- **剧情总结**：点击「📋 总结」AI 生成当前剧情摘要
- **多对话切换**：点击「💬 对话」按钮弹出列表，随时切换
- **角色图鉴**：点击「📖 图鉴」打开右侧面板，记录每个角色的好感度、性格、状态等
- **快捷输入**：自定义短语按钮，一键发送

### 回复长度 & 互动选项

每次对话可独立配置：

| 选项 | A | B | C | D（默认） |
|------|---|---|---|------|
| 回复长度 | 3000+字 | 1500字 | 800字 | 自主决定 |

| 选项 | F（默认） | T |
|------|----------|---|
| 互动选项 | 不提供选项 | 末尾提供 [SUGGESTIONS] 选项 |

## ⚙️ AI 配置

### 添加配置

点击「+ 添加配置」→ 在快捷预设中选择模型，填入 API Key，保存。

**内置预设**：

| 模型 | API 地址 |
|------|---------|
| Ollama 本地 | `http://localhost:11434` |
| DeepSeek V4 Pro | `https://api.deepseek.com` |
| DeepSeek V4 Flash | `https://api.deepseek.com` |
| DeepSeek V3 | `https://api.deepseek.com` |
| DeepSeek R1 | `https://api.deepseek.com` |
| GPT-4o / GPT-4o-mini | `https://api.openai.com` |
| Claude 3.5 Sonnet | `https://api.anthropic.com` |
| Qwen Max | `https://dashscope.aliyuncs.com/compatible-mode` |
| GLM-4 | `https://open.bigmodel.cn/api/paas/v4` |
| Moonshot | `https://api.moonshot.cn` |

### 参数说明

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| 温度 | 控制随机性。低→稳定，高→创意 | 0.7~0.9 |
| Max Token | 单次回复上限 | 8192 |
| Top P | 核采样，1.0=不限制 | 0.9~1.0 |
| 频率惩罚 | 防重复用词 | 0~0.3 |
| 存在惩罚 | 倾向新话题 | 0~0.3 |

### 故障转移

选择一个配置作为"当前使用"，另选一个作为"备用"。主配置失败时自动切换。

### 提示词模板

7 个内置模板，决定 AI 的系统提示词风格：

- **默认**：标准角色扮演
- **古风角色**：仙侠/武侠/古装
- **现代角色**：都市/校园/职场
- **RPG 旁白**：跑团/冒险
- **亲密关系**：恋爱向
- **叙事创作系统**：三位一体 v3.0 商业网文策划
- 支持自定义模板

### 全局规则 & 主角设定 & GM 设置

- **📜 全局规则**：所有对话自动注入的规则（如"始终用中文回复"）
- **🧑 主角设定**：设定你在故事中的身份，可选全局生效
- **🎲 GM 设置**：叙事风格、细节程度、节奏、骰子判定

### 快捷输入

设置 5 个快捷短语，聊天时在输入框上方显示为按钮，点击直接发送。在聊天页可折叠/展开。

## 🛠 开发

### 技术栈

Electron 33 + React 18 + TypeScript + Vite 6 + Tailwind CSS 3 + Zustand 5 + SQLite (sql.js WASM)

### 本地运行

```bash
git clone https://github.com/yourname/scriptweaver.git
cd scriptweaver
npm install
npm run dev          # 开发模式
npm run typecheck    # 类型检查
npm run build:win    # 打包 Windows
npm run build:mac    # 打包 macOS
npm run build:linux  # 打包 Linux
```

### 项目结构

```
├── electron/          # 主进程
│   ├── main.ts        # 窗口、生命周期
│   ├── preload.ts     # 安全 IPC 桥
│   ├── database.ts    # SQLite CRUD
│   ├── safe-storage.ts # 密钥加密
│   └── ipc-handlers.ts # IPC + SSE 流式
├── src/
│   ├── pages/         # 7 个页面
│   ├── components/    # 14 个组件
│   ├── stores/        # 6 个 Zustand store
│   ├── lib/           # 工具函数
│   └── types/         # TS 类型
└── package.json
```
