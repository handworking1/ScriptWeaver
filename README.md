## 快速上手

> 📦 首次启动已内置示例剧本「苍玄录」+ 4 个角色，可直接体验。

### 1. 下载安装（1 分钟）

从 [Releases](../../releases) 下载 `叙世-Setup-x.x.x.exe` 安装或 `叙世-x.x.x-免安装版.zip` 解压即用。首次启动自动植入示例剧本和角色。

### 2. 配置 AI（2 分钟）

左侧导航 → **设置** → 点击「+ 添加配置」：

- 快捷预设选择模型（`DeepSeek V4 Pro` 推荐）
- 填入 API Key（加密存储，仅本地保存）
- 点「🔌 测试」→ 通过后点「保存」

> 💡 也可用本地 Ollama：装好 [Ollama](https://ollama.com) → `ollama pull qwen2.5:14b` → 选 `Ollama 本地` 预设，无需 API Key。

### 3. 体验聊天（30 秒）

左侧导航 → **聊天**：

- 剧本选「苍玄录」→ 角色选「苏灵儿」→ 配置选刚保存的
- 点 `💬 开始对话`
- 输入消息 → 发送，AI 即刻回复！

### 4. 探索更多

| 我想... | 去这里 |
|---------|--------|
| 自己写一个剧本 | 剧本管理 → + 新建 → ✨ AI 补全 |

### 📤 从小说提取剧本

上传 .txt/.md 小说或粘贴文本，AI 自动提取 18 个设定字段：

- 标题、世界观、故事背景、类型标签
- 主线/支线任务、章节划分、对标作品
- 环境描述、地图、势力体系、事件时间线
- **自动创建角色**（姓名+性格+背景+口癖+外貌）
- **世界信息词条**（重要地点/门派/法宝 → Lorebook）
- 智能采样：百万字 → 1.3 万字精要 → 1 次 API 调用

### 📝 文风模仿

切换到「📝 分析文风」标签：

- AI 分析 6 维风格画像（句式/用词/描写/对话/节奏/视角）
- 自动选取开头+中段+结尾 3 段参考示例
- 剧本设置新增「文风模仿」开关，开启后每次对话自动注入
- 风格块不会被后续对话剥离

## 🤖 AI 剧本讨论

独立的剧本讨论页面，和 AI 按**十二步工作流**协作：

1. **第零步**（可选）：对标作品学习 → AI 解析文风、世界观、情节模式
2. **第一步**：一句话概括（25 字：谁+什么情况+什么方式+什么结果）
3. **第二步**：一段式概括（三幕结构+三次灾难+道德前提）
4. **第三步**：一页人物介绍（人名/身份/目标/抱负/价值观/矛盾）
5. **第四步**：一页大纲（可配置 A故事级/B幕级/C序列级/D场景级）
6. **第五步**：人物大纲（深挖过去经历和原生家庭）
7. **第六步**：四页大纲（每段扩展为一页）
8. **第七步**：动态实体知识库（追踪角色/物品/地点变化）
9. **第八步**：场景清单
10. **第九步**：规划场景（视点人物/目标/冲突/挫折）
11. **第十步**：生成全文
12. **第十一步**：书名与简介

### 特殊功能

- **💡 快捷提问**：空白区三个快捷按钮——「帮我想一个世界观」「帮我设计一个主角」「帮我规划剧情结构」，一键开始讨论
- **👥 提取角色**：点击按钮，AI 自动从讨论中识别所有角色 → 点击角色名一键添加到角色管理
- **📝 生成剧本**：讨论完成后一键生成完整剧本，直接保存

### 聊天功能

- **流式输出**：AI 回复逐字显示，打字机效果
- **选项卡片**：AI 回复中的 `[SUGGESTIONS: 选项1 | 选项2 | 选项3]` 自动转为可点击卡片
- **编辑消息**：hover 用户消息出现编辑按钮，修改后重新生成
- **重新生成**：点击按钮重新生成最后一条 AI 回复
- **对话分支**：在当前节点创建分支对话，独立发展
- **剧情总结**：点击「📋 总结」AI 生成当前剧情摘要
- **多对话切换**：点击「💬 对话」按钮弹出列表，随时切换
- **🔍 对话内搜索**：头部搜索框实时过滤消息，显示匹配条数
- **📜 剧本速览**：点击「📜 剧本」侧边抽屉查看完整设定（世界观、主线、金手指等）
- **↩ 撤销发送**：一键删除最后一条用户消息及 AI 回复
- **快捷输入**：自定义短语按钮，一键发送
- **📑 章节标记**：点击「📑 章节」标记场景/章节起点，消息流显示紫色分隔条，支持从剧本章节预设下拉选择，AI 自动检测场景切换信号并提示
- **⭐ 精彩标注**：每条消息底部 ⭐ 按钮收藏/取消，头部筛选只看出标注消息，阅读模式中高亮
- **📖 小说阅读**：点击「📖 阅读」全屏沉浸式阅读，对话自动转为连续小说体，自动插入章节标题，⭐ 标注高亮，可选隐藏用户行动，支持 📥 导出 Markdown
- **💬 角色图鉴 → 关系图**：图鉴面板新增「🔗 关系」标签，SVG 可视化角色关系网（暗恋/挚友/师徒等 15 种关系），节点可拖拽

### @私聊（世界模式专属）

在世界参与模式下，输入 `@` + 角色名前缀即可唤起角色选择面板：

```
你: @苏
┌─────────────────────┐
│ 苏灵儿  · 小师妹    │  ← 点击选择角色
│ 苏长老  · 宗门前辈  │
└─────────────────────┘
```

- 选择后自动创建新的私聊标签页，与该 NPC 进行独立对话
- 支持多字姓名（上官婉儿、欧阳锋等），中文 Unicode 精确匹配
- 各 NPC 私聊互不干扰，切换标签即可回到世界主线

| 功能 | 说明 |

| + 添加 | 手动添加角色卡片 |
| ✕ 删除 | 移除角色 |

| 性格 | 自由文本 |

所有数据持久化保存至数据库，与剧本关联，切换对话不丢失。

