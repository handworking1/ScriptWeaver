# Icons

Place your app icons here for electron-builder packaging:

- `icon.ico` — Windows (.ico format, 256x256 recommended)
- `icon.icns` — macOS (.icns format)  
- `icon.png` — Linux (.png format, 512x512 recommended)

You can generate these from a single 1024x1024 PNG using:
- https://iconverter.com (online)
- Or `npx electron-icon-maker --input=icon.png --output=./public`
